About This Resource

A layered research strata and source dig built around a shared OrientDig spreadsheet.

What this resource is

This is an independent informational and navigation resource for people who use an OrientDig spreadsheet. It offers a layered method — surface label, row context, current destination, and open questions — so each row is researched one layer at a time.

What this resource is not

This resource is not the official OrientDig website, and it is not affiliated with, endorsed by, or operated by OrientDig or Google. It is not a store, an automatic deduplicator, a link converter, a QC scorer, or a shipping calculator.

The strata method

Everything here follows four layers: Surface label (what the cell says), Row context (headers, adjacent fields, category), Current destination (what the page shows now), and Open questions (what is missing, conflicting, or unconfirmable).

How to use it

  1. Open the shared Google Sheet to see the listing references.
  2. Browse the twelve product categories from the home page.
  3. Read the three guides before relying on any listing clue.
  4. Research each row layer by layer and re-check the destination.

Research example — not a live listing or verification result.
